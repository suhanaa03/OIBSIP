# House Price Prediction with Linear Regression

## Objective

Build and evaluate a machine learning model that predicts house prices using property features such as area, location, number of rooms, and age.

## Tech Stack

* Python
* pandas
* scikit-learn
* matplotlib
* seaborn
* Jupyter Notebook

## Workflow

1. Load dataset
2. Perform EDA
3. Handle missing values
4. Encode categorical variables using One-Hot Encoding
5. Correlation analysis
6. Train/test split (80/20)
7. Train Linear Regression model
8. Evaluate using MSE, RMSE, and R²
9. Visualize predictions and residuals
10. Analyze feature coefficients
11. Compare with Ridge Regression

## Results

The Linear Regression model achieved a strong R² score and identified Overall Quality, Living Area, Garage Capacity, and Neighborhood-related features as major contributors to house prices.
